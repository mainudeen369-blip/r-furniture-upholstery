# R Furniture Upholstery — Dubai

Premium static website for R Furniture Upholstery, built with Next.js 15.

## Features

- Bilingual **English / Arabic** with RTL support
- Luxury gold & brown brand theme matching client flyers
- Framer Motion scroll and entrance animations
- Fully responsive (mobile, tablet, laptop, desktop)
- WhatsApp integration (+971 56 769 2414)
- Static export for easy hosting

## Development

```powershell
cd C:\HajaWorkingFolder\oldFiles\R
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Production Build

```powershell
npm run build
```

Static files output to `out/` — deploy to Netlify, Vercel, or any static host.
